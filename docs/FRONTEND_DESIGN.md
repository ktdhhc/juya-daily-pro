# FRONTEND_DESIGN · 「合订本」印刷编辑设计

> **状态**：基准契约（2026-08-28 由用户目标激活——界面去"AI 味"重设计，本文先行防止漂移）。
> 所有新视图（/stream、/company、/company/[id]）与旧组件改造都必须遵循本文；实现与本文冲突时，改实现而不是改本文。修改本文需在 commit message 中显式声明。

## 1. 诊断：现在哪里有"AI 味"

当前前端与 `demo/index.html` 原型的交互元素存在一组典型的"AI 产品通用脸"：

| AI 味来源 | 具体表现 |
|---|---|
| 圆角卡片 + 柔阴影 | `rounded-lg` 卡片、`shadow-md/lg`、悬浮上浮 hover，SaaS 后台脸 |
| 胶囊徽章 | `company-chip` 等 rounded-full 彩色 pill，一排小糖豆 |
| 脉冲骨架屏 | `animate-pulse` 灰块，ChatGPT 式 loading |
| 渐变与霓虹 | cyber 主题的霓虹辉光、渐变强调色 |
| 均质居中 | 一切内容居中对齐、hero 式标题、对称栅格 |

这些手法让产品看起来像"又一个 AI 工具"，而不是它本来的身份——**一份日报**。

## 2. 方向：把"报纸基因"贯彻到底

产品自带报纸骨架（AI 早报 / 概览 / `#N` 编号 / 一期一份 / 前后期导航）。设计不做加法，做**提纯**：整个界面应当像排版工坊里的一摞合订本，而不是一个 app。

六字方针：**纸、墨、线、印、号、静**。

1. **纸** — 暖白纸底，拒绝纯白与深灰卡片。层级靠纸张深浅（`--bg` / `--bg-warm`），不靠框。
2. **墨** — 近黑墨色文字，层级靠字重与字号，不靠颜色种类。链接一律下划线，不做彩色按钮。
3. **线** — 细线（hairline，1px）承担全部分隔职能：条目之间、表头之下、页脚之上。**不画框、不加阴影、不用底色块包内容**。
4. **印** — 全站唯一"实心元素"是**方形钤印**：品牌印与公司印。方形小印（1-2 个汉字），替代一切圆形/胶囊徽章。
5. **号** — `#N` 编号是排版主角而非标签：边栏大号细体数字，像报纸页边码。
6. **静** — 动效克制如墨迹阴干：只有 150ms 的透明度与位移过渡，无脉冲、无弹跳、无辉光。

## 3. 设计 Token（在现有 6 主题体系上追加）

现有主题机制（data-theme + CSS 变量）保留——6 套主题只变配色与字体，**全部继承本节的形状规则**：

```css
--rule: color-mix(in srgb, var(--fg) 18%, transparent); /* 细线色，随主题走 */
--seal: var(--accent);            /* 钤印色 = 主题强调色 */
--radius-inprint: 0;              /* 卡片、徽章、按钮、输入框圆角一律 0 */
--dur: 150ms;                     /* 全站唯一过渡时长 */
```

- `border-radius: 0` 适用于：卡片、印章、按钮、输入框、弹窗、下拉。唯一例外：阅读进度条（无形状语义）。
- 禁止新增：`shadow-*`、`rounded-full` 徽章、渐变背景、辉光。cyber 主题收敛为"终端打印纸"：暗纸底 + 单一荧光强调色，去 glow。
- 字体：标题用主题衬线；`#N`、日期、元数据用等宽或 tabular-nums。

## 4. 交互元素规格

### 4.1 报头 Masthead（全站共用 Header，改造）

- 左：品牌**方印**——正方形钤印内单字「橘」，旁边站名「橘鸦 AI 日报」横排。
- 中：Nav 三联「日报 / 事件流 / 公司」为**栏目名**，宽字距（letter-spacing 0.15em）；激活态 = 文字下方 3px 墨线，**不是** pill/底色块。
- 右：刊号（`第 N 期 · YYYY-MM-DD`，等宽数字）+ 主题切换 + 合订本入口（细线描边图标，非填充）。
- 报头底边 1px 细线；阅读进度为报头下 2px 墨线。

### 4.2 条目 Item（/stream 与公司页复用，核心组件）

**没有卡片盒**。一条 Item 是一段由细线划开的排版块：

```text
──────────────────────────────────────────   ← 1px 细线（条目分隔）
 #3 │ OpenAI 称误路由 5.5-mini 问题已修复并致歉 ↗   ← 边栏编号 + 衬线标题
要闻 · 08-27                                      ← 元数据行（小字）
    摘要文字 15px / 1.7 行距 / --fg-light ……
    相关链接 4 · [印][印]                          ← 脚注行：相关链接数 + 公司钤印
```

- 左栏固定 48px 放 `#N`：大号细体等宽数字（18px / weight 300），像页边页码；无主链接条目（同日后续）编号位显示 `·`。
- 公司钤印（**替代 company-chip**）：18px 正方形；多公司并列等尺寸一行（v1 无主次，ADR-0014）；单字取公司名首字，hover 出全名 tooltip；实心印 = 当前语境主公司，描边印 = 提及公司。
- hover 态：仅整块背景从 `--bg` 变 `--bg-warm`，**不上浮、不出阴影**。
- "看原期"为主链接 ↗ 的同级文字脚注，不单独做按钮。

### 4.3 索引 Facet 栏（/stream 左侧筛选）

- 分组标题（公司 / 分类 / 时间）用**竖排**小字（writing-mode: vertical-rl），右侧细线，像报纸中缝目录。
- 选项是文字列表 + 墨点状态（`●` 选中 / `○` 未选），**不是** checkbox/pill。
- 日期范围：两个内联日期输入，聚焦时下边线变 2px 墨线（无圆角输入框）。
- 筛选变化写入 URL query（ADR-0012）；激活的 facet 在报头下显示可删除的小字标记。

### 4.4 合订本日期索引（替代现有日历弹窗）

- 弹窗即合订本目录：按月分节，左侧竖排月份（「二〇二六年八月」），右侧日期为裸数字网格。
- 当前阅读期：数字上压一枚小方印；有内容日期为墨色，无内容为 `--fg-subtle`。
- 交互与现有 DatePicker 数据模型兼容（entries 列表驱动），只重排视觉。

### 4.5 排版中骨架（替代 animate-pulse）

- 静态灰版：与真实排版同构的细线轮廓块（标题条、正文行、边栏编号位），无任何动画。
- 左下角竖排小字「排版中 …」，加载完成整块 150ms 淡入。

### 4.6 空态与错误

- 竖排短语（如「无如是期」/「未有所获」）+ 一行说明 + 文字链式重试（下划线），无插画、无按钮底色。

## 5. 动效规则

| 场景 | 规则 |
|---|---|
| 主题切换 | 0ms 直接切换（纸质品不渐变） |
| 视图切换（Nav） | 内容 150ms opacity 淡入 |
| hover | 背景 150ms；细线颜色 150ms |
| 弹窗（合订本） | 150ms opacity + 4px 上移，无缩放 |
| 骨架→内容 | 150ms opacity |
| 禁用 | animate-pulse、bounce、scale、glow、marquee |

## 6. 实施边界

- **Spec 04（三视图）起全面按本文实现**；既有阅读页组件（Header/DatePicker/ArticleView）在 spec 04 内做一致性改造（报头、合订本、骨架），不做无关重排。
- 形状规则落在 globals.css 公共类（`.rule-t` `.seal` `.v-label` 等），组件不重复内联；Tailwind 优先 `rounded-none`。
- 多模态验证：spec 04 完成后用浏览器截图对照本文逐条核对（含 hover 态、弹窗、骨架）。
- 6 套主题调色不改动现有变量名与语义，仅在 spec 04 内核对 cyber 去辉光、各主题 `--rule` 对比度可读。
