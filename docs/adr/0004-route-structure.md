# 路由结构：四路由静态导出

四个路由，每个职责单一，URL 可分享。Next.js 16 静态导出原生支持，切换走软导航几乎瞬时。

- `/`                 当前期阅读页（现状不变，`?date=` 同步）
- `/timeline`         全局时间线 + 左侧 facet 筛选
- `/company`          公司索引页（按字母或事件数排序的卡片墙）
- `/company/[id]`     单公司页（该公司所有事件按时间倒序）

顶部 Header 在四页共用，新增 Nav 三联：`日期 | 时间线 | 公司`，右边保留 ThemeToggle。
首页默认仍是当前期阅读，不打破已有的 `?date=` 分享习惯。
